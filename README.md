Questa repository contiene una pipeline completa e configurabile in Python per scaricare, processare e analizzare spazialmente i dati sismici.

Sviluppato originariamente per il monitoraggio dei **Campi Flegrei**, il codice e stato generalizzato per applicare le stesse analisi geospaziali a qualsiasi area del mondo.
